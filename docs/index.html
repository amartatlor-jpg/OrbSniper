What are Orbs?

Orbs are Discord's own currency. You earn them by finishing Quests — those sponsored "play this game for 15 minutes" tasks. A typical quest pays around 700 Orbs.

Seven decorations can only be bought with Orbs — no money gets them. The catch is that quests want you to actually install games and sit through them. OrbSniper does that part instead, so you spend time, not money.

How it works

  1. Checks before it startsIs Discord installed, are its settings writable, is the port free, does the network answer. Something's wrong — it says so instead of dying halfway.
  2. Relaunches your DiscordWith a debugging port, then injects the quest logic. Your token is never read — every request comes from Discord itself.
  3. Farms while you do other thingsAccepts quests, completes them, claims rewards. New quests are picked up every 20 seconds.
  4. Tells you when it's doneShows the score and reminds you about rewards Discord wouldn't hand over automatically.
